# Coffee Shop

A responsive single-page coffee shop website with menu, reviews (Swiper slider), and a table booking form.

## Pages

- `index.html` — Landing page with home, about, menu, reviews, booking, and footer sections

## How to open

Double-click `index.html` in a browser, or serve locally:

```console
python -m http.server 8000
```

Then visit http://localhost:8000.

## Tech stack

- HTML5, CSS3, JavaScript
- [Swiper](https://swiperjs.com/) for the review carousel
- [Font Awesome](https://fontawesome.com/) for icons
- [Google Fonts — Poppins](https://fonts.google.com/) for typography

## Notes

- External CDNs (Swiper, Font Awesome, Google Fonts) are required for full functionality.
- The booking form is front-end only; connect a backend or form service to process submissions.
